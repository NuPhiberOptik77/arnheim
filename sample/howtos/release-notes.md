# Write release notes

Made up, like the rest of Fernhollow.

Release notes are for the people who use the app, not for us.

- Start with what they can do now that they couldn't before.
- Then what was fixed, in their words: "the bookmark no longer jumps back a page".
- Leave out file names, ticket numbers and anything about how it was built.
- Keep it under a hundred words.

```
New: a warmer night theme, easier on the eyes.
Fixed: the bookmark no longer jumps back a page.
```
