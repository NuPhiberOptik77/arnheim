# Add a kite template

Made up, like the rest of Fernhollow.

1. Copy `templates/delta.json` to a new file named after the kite.
2. Change the sail's points and the spars. Keep the units in centimetres.
3. Run `npm run sim -- --template <name>` and watch one flight in light wind and one in strong wind.
4. Add a picture of the flight to `templates/pictures/`.

The wish list in `notes/templates.md` says which kites people asked for most.
